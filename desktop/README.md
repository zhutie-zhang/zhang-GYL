# 海外仓管理看板 - 桌面版

把原来的网页版看板打包成桌面软件：双击即开独立窗口，不弹浏览器、不用输网址，后台服务自动拉起并在关闭窗口时自动退出。

## 快速开始（当前机器已就绪）

双击 **`启动桌面版.vbs`** 或 **`桌面版.cmd`**，桌面窗口即打开，数据与网页版完全一致。

也可以手动启动（调试用）：
```
node_modules\.bin\electron.cmd .
```

## 功能说明

- 启动后自动拉起后端服务（端口 8000），就绪即显示看板
- 若 8000 已被网页版占用，桌面版直接复用该服务（不重复启动、数据不冲突）
- 关闭窗口 → 后端自动清理退出；单实例锁（不会开两个窗口）
- 异常退出有错误提示框

## 目录结构

```
desktop/
  main.js          桌面主进程（拉起后端/开窗口/退出清理）
  package.json     依赖与打包配置
  启动桌面版.vbs   双击运行入口（推荐）
  桌面版.cmd       备选入口
  打包为EXE.bat    一键打包为安装程序（需网络）
  build/icon*      应用图标
```

## 打包成正式安装程序

在能访问 GitHub 的机器上（或配好代理），双击 **`打包为EXE.bat`**，或：

```
npm run dist
```

产物在 `dist\海外仓管理看板 Setup 1.0.0.exe`，可分发给其他装有 Python 的机器。

## 已知限制

- 依赖本机已安装 Python 3.13+ 及工程所需的第三方包（flask、waitress、requests、openpyxl、PIL 等）。若换机器使用，需先在新机器装好这些依赖。
