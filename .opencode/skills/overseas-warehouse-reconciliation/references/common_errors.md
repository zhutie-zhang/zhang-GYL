# 海外仓常见计费错误模式

## 一、重复计费

### 1.1 同一服务多次收费
- **模式**: 同一笔业务在账单的不同行中被重复列出
- **检测方法**: 按(费用类型 + 日期 + 数量 + 单价)组合去重，识别完全相同或近似重复的行
- **示例**: 1月5日 打托费 10托 × $5，在账单中出现了两次

### 1.2 服务包含关系重复
- **模式**: 一个费用项目实际已包含在另一个费用中，但仍被单独列出
- **常见组合**:
  - 拆柜费已包含打托 → 又单独收打托费
  - 处理费已包含上架 → 又单独收上架费
  - 退货费已包含分拣 → 又单独收分拣费
  - 装车费已包含在出仓处理费中 → 又单独收装车费
- **检测方法**: 需参考报价表中的费用包含说明（remark字段），若报价中注明"含XX"则不应再单独收费

### 1.3 入仓出仓双重收费
- **模式**: 报价中约定处理费按"进出各一次"计费，但账单中按入仓+出仓分别全额收取
- **检测方法**: 核对报价中处理费的计费逻辑，确认是per inbound+outbound还是per shipment

## 二、仓租天数计算错误

### 2.1 入库日出库日双重计费
- **模式**: 账单将入库当天和出库当天都计为仓租日
- **正确计算**: 通常应按"出库日 - 入库日"计算天数（不包含入库当天），或按双方约定执行
- **检测方法**: 用账单中的入库日期和出库日期重新计算天数，与账单天数比对

### 2.2 免租期未扣除
- **模式**: 报价中约定前N天免租（如前7天免仓租），但账单从入库第一天就开始计费
- **检测方法**: 从报价表读取 free_days 字段，验证账单中仓租的起始日期是否跳过了免租期

### 2.3 周末/节假日计费
- **模式**: 报价中约定周末不计费，但账单中周末也计了仓租
- **检测方法**: 检查报价remark中是否有"周末不计费"或"Weekend free"等说明，如有则剔除账单中的周末天数

### 2.4 仓租基数错误
- **模式**: 报价按CBM/天计费，但账单使用了错误的体积数据（如入仓时体积 vs 出库时体积，取大值）
- **检测方法**: 核对账单中使用的体积数据是否与实际入仓体积一致

### 2.5 按月计费但按天累加
- **模式**: 报价中仓租按月计费（如$15/CBM/月），但账单将月费率除以30后按天累加，导致月末天数多算
- **检测方法**: 比对月计费与日计费两种方式的总金额差异

## 三、单价错误

### 3.1 单价高于报价
- **模式**: 账单中某项费用的单价高于报价表中约定的单价
- **检测方法**: 逐行比对账单单价与报价表单价

### 3.2 汇率错误
- **模式**: 账单使用非约定汇率进行换算
- **检测方法**: 检查账单中是否有汇率信息，核对是否使用了约定汇率

### 3.3 阶梯报价未按实际量降档
- **模式**: 报价表中有阶梯价格（如月处理量>1000箱单价降低），但实际量已达降档标准仍按高档单价计费
- **检测方法**: 汇总当月总处理量，检查是否触发阶梯降价

## 四、数量错误

### 4.1 虚高件数/箱数
- **模式**: 账单中的处理件数/箱数高于实际入库通知单或出库订单中的数量
- **检测方法**: 用入仓单/出库单的实际数据核对账单数量

### 4.2 CBM取整方式不一致
- **模式**: 报价约定CBM保留两位小数，但账单按向上取整计算
- **检测方法**: 重新计算实际CBM，与账单CBM比对

### 4.3 托数虚高
- **模式**: 实际打托数量低于账单中的托数
- **检测方法**: 核对打托照片/入库确认单中的托数

## 五、不合理杂费

### 5.1 未在报价中的费用
- **模式**: 账单中出现报价表中不存在的费用项目
- **检测方法**: 将账单费用项目与报价表逐项比对，标记未匹配项

### 5.2 过高杂费
- **模式**: 杂费金额占总费用比例异常高（通常杂费占比不应超过总费用的5-10%）
- **检测方法**: 计算杂费占比，超过阈值时标记

### 5.3 模糊费用描述
- **模式**: 费用名称模糊不清（如"Other Fee", "Miscellaneous", "杂费"），无法对应到具体服务
- **检测方法**: 检查费用名称是否在标准费用类型映射中，未匹配的标记为需确认

## 六、异常检测规则汇总

| 规则编号 | 错误类型 | 检测方法 | 严重级别 |
|---------|---------|---------|---------|
| R01 | 重复计费-完全重复 | (fee_type+date+qty+price)去重 | 高 |
| R02 | 重复计费-包含关系 | 检查报价remark中的"含"字说明 | 高 |
| R03 | 仓租天数错误 | 重新计算入库到出库天数 | 高 |
| R04 | 免租期未扣 | 检查free_days是否被跳过 | 高 |
| R05 | 周末计费 | 检查remark中的周末条款 | 中 |
| R06 | 单价高于报价 | 逐行比对单价 | 高 |
| R07 | 汇率错误 | 核对约定汇率 | 中 |
| R08 | 阶梯未降档 | 汇总月度量检查阶梯 | 中 |
| R09 | 件数虚高 | 比对入/出库单数量 | 高 |
| R10 | CBM取整不一致 | 重新计算CBM | 低 |
| R11 | 未报价费用 | 比对报价表费用项目 | 中 |
| R12 | 杂费占比过高 | 计算杂费/总费比例 | 中 |
| R13 | 模糊费用描述 | 检查费用名称匹配度 | 低 |
